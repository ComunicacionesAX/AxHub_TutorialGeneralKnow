Proceso etl y flujo

El proceso de automatización y carga de datos sigue estos pasos:

  • check_circle Automatización de fuente de información (Excel cliente/captura/genética)
  • check_circle Tiempo máximo: 10 días hábiles
  • check_circle Construcción paralela de modelo de visualización
  • check_circle Carga de archivo al filemanager designado
  • check_circle Recepción de correo con resultado del proceso

schedule Actualización de datos

  • info Si el proceso es exitoso, los datos se reflejan en el modelo en la siguiente hora de actualización
  • info Las actualizaciones inician cada hora a partir de las 5:15 a.m.

    El archivo no se pudo cargar

    📧 El correo dice "falló" y estos son los casos:

    Caso 1: Empresa o granja nueva
    Hola!

El proceso de ETL para el archivo S4 - JUAN FONSECA - VALLE - BUGA - PRIMERIZAS - 2025 EDESMA.xlsx falló debido a que:
•	No se encontró información de metadata para 7 registros con la siguiente combinacion de origenDatos, empresa y granja: "Contegral - Goloso Del Valle - Ledesma". (requerido)
•	No se encuentra la columna lineaGeneticaMadre2 requerida para la limpieza de lineaGeneticaMadre. (requerido)
•	No se encuentra la columna lineaGeneticaPadre2 requerida para la limpieza de lineaGeneticaPadre. (requerido)
•	No se encuentra la columna proveedorNutricionalDetallado1 requerida para la limpieza de proveedorNutricional. (requerido)
•	No se encontraron las columnas requeridas lineaGenetica2, proveedorNutricional2, pais, departamento y municipio. (requerido)

    📞 ¿Qué haces?

    • ✅ ¡No subas nada! Esto no es error tuyo
    • ✅ Llama a Asimetrix: 3053907711
    • ✅ Diles: "Mi granja es nueva, no me deja subir archivos"
    Caso 2: No hay información o archivo mal estructurado
    NO HAY INFORMACION EN EL ARCHIVO O ESTA MALA
Hola!

El proceso de ETL para el archivo S4 - KAREN RENDON - ANTIOQUIA - LAS CACHAMERAS - 2025.xlsx falló debido a que no se detectó mapping activo para la carpeta seleccionada.

    🔧 ¿Qué haces?

    • ✅ Abre tu archivo de Excel
    • ✅ Revisa que tenga información adentro (filas con datos)
    • ✅ Asegúrate que las columnas tengan nombre (ej: "edad", "peso", "fecha")
    • ✅ Guarda y súbelo otra vez
    Caso 3: Faltan llaves únicas obligatorias
    FALTAN LLAVES ÚNICAS OBLIGATORIAS
Hola!	

El proceso de ETL para el archivo POSTURA-FINCA AVICOLA LEAL REY LOTE 12.xlsx se ejecutó con las siguientes observaciones:
1.	No se pudieron procesar los datos de producción ponedoras debido a que se encontraron valores nulos para las columnas noGalpon y consumoAcumuladoG las cuales no permiten este tipo de dato. 
2.	Se procesaron exitosamente los datos de levante ponedoras con 2 registros insertados y 0 registros actualizados en la tabla performance_layergrower en Aurora. Es importante tener en cuenta que no se cargó toda la información debido a que para la siguiente combinación de empresa, granja, idLote y noGalpon: "Avicola Leal Rey - El Recuerdo - 12 - Y-Z" se encontraron 15 registros sin la edad minima requerida, semana 1.

3.	No se pudieron procesar los datos de ponedoras clasificacion huevo debido a que se encontraron datos nulos para la key noGalpon.

    🔧 ¿Qué haces?

    • ✅ Revisa qué columnas faltan (te las dice el correo)
    • ✅ Pídele al que llena el archivo que las agregue
    • ✅ Columnas comunes que piden: pais, departamento, municipio, tipo de genética
    • ✅ Guarda y súbelo otra vez
